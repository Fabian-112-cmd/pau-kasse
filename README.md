# Bader-PAU Kasse

Grundversion für iPhone und iPad. Beispielpreise bitte vor der Verwendung anpassen.

## GitHub Pages
Alle Dateien dieses Ordners in das Hauptverzeichnis eines eigenen GitHub-Repositorys hochladen (ZIP vorher entpacken). Unter Settings → Pages die Veröffentlichung aus dem Branch main und dem Ordner / (root) auswählen.

## Home-Bildschirm
Den veröffentlichten Link in Safari öffnen → Teilen → Zum Home-Bildschirm. Das PAU-Kasse-Symbol ist enthalten.

## Bearbeiten
Artikel und Preise direkt in der App bearbeiten. Aufbau: index.html (Seite), style.css (Aussehen), app.js (Funktionen und Ausgangsartikel).

Einstellungen und Tageszahlen werden pro Browser und Gerät gespeichert. Ein anderer Web-Link hat einen eigenen Speicher; Daten der bisherigen App werden nicht automatisch übernommen. Keine Synchronisation zwischen Geräten. Beim Löschen der Browserdaten gehen die lokalen Daten verloren.

Artikel & Preise: Start-PIN 1234. PIN im geschützten Bereich ändern. Lokale Bediensperre, keine serverseitige Zugriffskontrolle.

Version 3: vierstelliger PIN beim Öffnen von Artikel & Preise. Start-PIN 1234.
Die Versionskennzeichnung V3 mit PIN bestätigt, dass die neue index.html geladen wurde.
